# Frequently asked questions

## Why doesn't Ctrl+Shift+E open Everything Search?

First try **Plugins > Everything Search > Open search**. If it opens the search field, check the shortcut assignment. The legacy Altap **Encrypt & Decrypt** plugin also used **Ctrl+Shift+E** for **Encrypt**. An older profile can still have that assignment. Open Samandarin no longer ships the encryption plugin.

1. Open **Plugins > Plugins Manager**. If **Encrypt & Decrypt** is listed, select it and choose **Keyboard**. Check whether **Encrypt** has **Ctrl+Shift+E** next to it.
2. If Encrypt owns the shortcut and you no longer use the plugin, close the shortcut dialog, select **Encrypt & Decrypt** in Plugins Manager and choose **Remove**. If you still use it, select **Encrypt** in its shortcut dialog, click **Clear** and confirm with **OK**.
3. In Plugins Manager, select **Everything Search** and click **Keyboard**. Under **Menu Items**, select **Open search**. Click **Press new shortcut key**, press **Ctrl+Shift+E**, then click **Assign**. Confirm with **OK** and close Plugins Manager.
4. With a disk panel active, press **Ctrl+Shift+E**. The search field should receive the caret. From the results, pressing it again should return you to the current query.
