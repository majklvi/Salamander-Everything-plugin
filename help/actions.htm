Working with results

Enable Parent folder in Settings to distinguish results with the same name. The plugin uses the full indexed path of the focused or marked item.

Enter
Open the focused file with its Windows association or enter the focused directory.
Shift+F3 — Open containing folder
Open the parent in the same panel and place the caret on the item without marking it. The shortcut also works in the query field once a result is available.
F3 and F4
View or edit the focused file.
F5 and F6
Copy or move the marked items to the opposite disk panel. With no marks, the command uses the focused item.
F8 or Delete
Delete the marked items or the focused item. Check the paths in the confirmation dialog.
Right-click
Open the Windows shell menu for the result.

Run history

Opening a file with Enter records a run with the Everything instance that supplied it. Viewing, editing, revealing, copying, moving and deleting through the plugin do not add runs. Choose Run count and Descending in Settings to see frequently opened items first.
