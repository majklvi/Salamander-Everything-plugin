Advanced Properties

In Settings, choose Advanced when connected to an Everything 1.5 instance offering additional properties. Everything 1.4 uses the standard columns.

  1. Type part of the property name in Filter properties. For example, type ength to find Name Length.
  2. Select the property. Check Show as result column to display it, or choose Use for sorting to order results by it. You can sort by a hidden property.
  3. Confirm the settings. Use Descending in the main dialog to reverse the order.

Available properties come from the selected Everything instance. A property can be blank for files for which the index has no value.
