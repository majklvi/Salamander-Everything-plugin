Open Samandarin: Plugins: Everything Search

Everything Search Settings

Choose Plugins > Everything Search > Settings.

Everything source
Automatic prefers a running Everything 1.4 instance. Select 1.4 or 1.5 explicitly to use its index when both are running. When the plugin loads, its Plugins menu entry uses the icon from the selected running executable. If the icon is unavailable, the entry is blank beside its label. Reload the plugin to refresh the icon after changing sources.
Result columns
The default view includes Name and Date modified. Enable Size, Parent folder, other dates or Run count as needed. Size and date formatting follow the host settings.
Current search order
Choose the property Everything sorts by before it returns a page. Check Descending to reverse it. A sort column can stay hidden.
Maximum results
The default is 200. Enter a larger number or 0 for all matches. Confirming the setting refreshes open searches. Large result sets take more time and memory to display.
