Open Samandarin: Plugins: Everything Search

Filtering results

Press Ctrl+F12 in the search field or results. Choose a mode and confirm with OK.

Do not use filter
Remove the active filter and keep the typed query.
Use filter
Apply a Samandarin filename mask, such as *.pdf;*.txt, to the rows returned by Everything. A matching file outside the result limit will not appear.
Use Everything Filter
Choose a saved filter by name. The list shows an abbreviated expression in parentheses. Everything applies the full expression together with the typed query before sorting and limiting the results. The panel path and tab show the active filter name.

Updating saved filters

The plugin loads built-in filters for the selected version and reads %APPDATA%\Everything\Filters.csv. A named instance uses its own Filters-<instance>.csv when available. A saved entry overrides a built-in filter with the same name. After editing or exporting filters in Everything, reopen Ctrl+F12 and confirm the updated definition.
